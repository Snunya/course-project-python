# Практическая работа №1 — вариант 2

Прототип веб-приложения с поддержкой удалённого вызова процедур.
На первом этапе реализована модель слоя доступа к данным, работающая
с данными в памяти. Для представления записей используются списки.

## Реализованные сущности

### Session

Поля записи:

- `uid` — идентификатор сессии;
- `created` — время создания;
- `error` — информация об ошибке.

Функции:

- `add_session()` — создание записи;
- `delete_session()` — удаление записи по идентификатору;
- `get_all_session()` — получение всех записей;
- `update_session()` — редактирование записи.

### Instruction

Поля записи:

- `uid` — идентификатор инструкции;
- `created` — время создания;
- `payload` — данные инструкции;
- `session_id` — идентификатор сессии;
- `description` — описание;
- `tags` — теги.

Функции:

- `add_instruction()` — создание записи;
- `delete_instruction()` — удаление записи по идентификатору;
- `get_all_instruction()` — получение всех записей;
- `update_instruction()` — редактирование записи.

### Response

Поля записи:

- `uid` — идентификатор ответа;
- `created` — время создания;
- `output` — результат;
- `stage` — этап обработки;
- `error` — информация об ошибке;
- `instruction_id` — идентификатор инструкции;
- `cache_hit` — признак попадания в кэш.

Функции:

- `add_response()` — создание записи;
- `delete_response()` — удаление записи по идентификатору;
- `get_all_response()` — получение всех записей;
- `update_response()` — редактирование записи.

## Специальная выборка

Функция `filtered_join()` выполняет соединение `Instruction` и
`Response`.

Выбираются ответы, созданные менее чем 6 минут назад, для которых
идентификатор инструкции совпадает с `Instruction.uid`.

Результат содержит:

- `Instruction.description`;
- `Response.cache_hit`;
- `Response.stage`.

Это соответствует формуле реляционной алгебры из задания варианта 2.

## REPL

Программа поддерживает интерактивный режим командной строки.

Доступные команды:

```text
add_session
show_sessions
update_session
delete_session

add_instruction
show_instructions
update_instruction
delete_instruction

add_response
show_responses
update_response
delete_response

join
exit
```

При удалении или изменении записи с отсутствующим идентификатором
выводится сообщение об ошибке.

## Запуск

Запуск приложения:

```text
python src/main.py
```

Либо в Windows:

```text
run.bat
```

Запуск тестов:

```text
python -m pytest
```

## Пример использования

После запуска:

```text
>> add_session 1 100 error
Сессия создана

>> show_sessions
[[1, 100, 'error']]

>> update_session 1 200 new_error
Сессия успешно обновлена

>> delete_session 1
Сессия удалена

>> delete_session 999
Сессия не найдена

>> join
Результат выборки: [...]
```

Данные хранятся только в памяти и удаляются после завершения
программы.
